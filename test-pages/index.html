Pages de démonstration

Pages locales servies en HTTP pour tester l’extension (cahier des charges §8.2).

  • Liste simple — tableau avec en-têtes, formulaire avec champs sensibles
  • Liste sans en-têtes — en-tête déduit, tableau de données seules, cellules vides
  • Cellules fusionnées — en-têtes sur deux niveaux, rowspan, colspan
  • Annuaire en cartes — liste non tabulaire, champ manquant, menu à ignorer
  • Fiche agent — paires libellé/valeur (dl, « Libellé : valeur », tableau clé/valeur, formulaire)
  • Contenu dynamique — tableau chargé après 1,2 s
  • Sélecteurs ambigus — tableaux identiques, en-têtes en double, identifiant en double
  • Agents du service RH — même tableau que la liste simple, colonnes dans un autre ordre, matricule manquant, doublon (réutilisation d’un scénario)

Pagination et fiches ouvertes par clic JavaScript : phase 5.
